Quickstart

Installation 
# Clone repository
git clone https://github.com/chaoshex/pure-lambda.git
cd pure-lambda

# Install dependencies
npm install

# Run basic verification
make verify
Basic Usage 
# Pack a seed
./cli/pack-seed.js --input data.json --output seed.car

# Verify a seed
./cli/verify-seed.js --seed seed.car

# Extract seed contents
./cli/unpack-seed.js --seed seed.car --output extracted/

Trust Model

Overview

Pure Lambda implements a multi-layer trust model based on cryptographic attestation and deterministic verification.

Core Principles

  • Deterministic Processing - All operations produce identical results across environments
  • Cryptographic Attestation - DSSE signatures provide provenance tracking
  • Offline Verification - Complete trust validation without network dependencies
  • Fail-Safe Operation - Graceful degradation to secure JSON mode
Verification Chain 
1. BIOLOCK Gate Validation
   ↓
2. DSSE Signature Check
   ↓
3. Hash Integrity Verification
   ↓
4. Schema Conformance Test
   ↓
5. Round-trip Validation
Security Guarantees
  • SHA-256 + BLAKE3 hash verification
  • Ed25519 signature validation
  • Runtime integrity protection
  • Zero-network operation capability

PL-SEED-01 Specification

Format Overview

PL-SEED-01 defines the canonical format for Pure Lambda seed packages.

Core Fields

  • gid - Global Identifier (content hash)
  • iid - Implementation Identifier
  • xid - Execution Identifier
  • payload - Primary data content
  • metadata - Descriptive information
Hashing Algorithm 
GID = BLAKE3(
    canonical_json(payload) +
    canonical_json(metadata) +
    schema_version
)
DSSE Integration 
# Sign a seed
./cli/sign-seed.js --seed input.car --key private.pem --output signed.car

# Verify signature
./cli/verify-signature.js --seed signed.car --pubkey public.pem
Round-trip Law

Invariant: pack(unpack(seed)) === seed

All PL-SEED-01 implementations must preserve this property for deterministic operation.

PL-FED-01 Federation Protocol

Overview

PL-FED-01 defines a standardized format for packaging, distributing, and verifying collections of Pure Lambda seeds as federation bundles with trust scoring and quarantine mechanisms.

Key Features

  • Offline Operation - Zero network dependencies after download
  • Trust Scoring - Algorithmic assessment based on signatures and conformance
  • Automatic Quarantine - Conflict detection for GID clashes
  • Deterministic Processing - Reproducible results across environments
Quick Usage 
# Create federation from seeds
make fed-ingest PATHS="hello-city.htmlc example.cartridge"

# Open federation hub (drag & drop interface)
open docs/federation/index.html

# Create distributable bundle
make fed-bundle && make fed-verify
Trust Score Formula 
score = 0.4 × dsse_ratio + 0.4 × conformance_ratio + 0.2 × freshness

Where:
- dsse_ratio = dsseValid / total_seeds
- conformance_ratio = conformant / total_seeds
- freshness = clamp(1 - ageMedian/365, 0, 1)
Score RangeLevelDescription
0.9 - 1.0ExcellentFully signed, conformant, fresh
0.7 - 0.89GoodMostly signed/conformant
0.5 - 0.69FairMixed trust indicators
0.3 - 0.49PoorLimited verification
0.0 - 0.29UntrustedUnsigned/non-conformant
SLOs for Production
  • Quarantine Count: 0 (zero quarantined seeds)
  • Trust Score: ≥ 0.8 recommended
  • Bundle Size: ≤ 80KB maximum
  • DSSE Coverage: ≥ 80% for "Good" rating

City-Cartridge: Portable Offline Packages

What is Cartridge

Cartridge is Pure Lambda's portable, verifiable, offline packaging format for distributing and executing seeds without network dependencies. Each cartridge contains a complete functional program with cryptographic signatures, manifest metadata, and an interactive viewer - all bundled for standalone operation.

Key Properties

  • Portable - Runs anywhere: browser, CLI, embedded systems
  • Verifiable - BLAKE3 + DSSE signatures ensure integrity
  • Offline - Zero network dependencies after download
  • Deterministic - Identical execution across all environments
Two Encoding Formats

📄 Single-HTML (.htmlc)

Self-contained HTML file with embedded cartridge data

≤ 40KB target Embedded viewer

📦 Zip Archive (.cartridge)

Structured archive with discrete components

≤ 80KB maximum Multi-file structure 
# Single-HTML structure
<script id="pl-cartridge" type="application/json">
  {MANIFEST_JSON}
</script>
<script id="pl-seed" type="text/plain">
  {BASE64_ENCODED_SEED}
</script>

# Zip Archive structure
hello-city.cartridge
├── index.html         # Interactive viewer
├── seed.json         # PL-SEED-01 format
├── envelope.json     # DSSE signature (optional)
└── manifest.json     # Cartridge metadata
Verify Locally (3 Steps)

Step 1: Hash Integrity

npm run cartridge:verify -- path/to/cartridge

Step 2: DSSE Signature (if present)

# Automatic verification with PL_ED25519_SECRET
make cartridge-verify

Step 3: Round-trip Law

# Verify pack(unpack(cartridge)) === cartridge
./cli/test-roundtrip.js --seed cartridge.htmlc
Quick Commands 
# Create both formats
make cartridge

# Open cartridge in browser
make cartridge-open

# Verify integrity
make cartridge-verify

# Pack from seed
npm run cartridge:htmlc -- --input seed.json
npm run cartridge:zip -- --input seed.json

# Extract from cartridge
npm run cartridge:extract -- --input hello.cartridge
Size Limits & DSSE Notes
  • Single-HTML (.htmlc): ≤ 40KB target size
  • Zip Archive (.cartridge): ≤ 80KB maximum size
  • DSSE Note: Cartridges MAY include Dead Simple Signing Envelope signatures using Ed25519 keys
  • Payload Type: application/vnd.pure-lambda.seed+json
  • MirrorBench Hash (#seed=hello-city): Provides deterministic test data for verification

Seed Workflows

Pack/Unpack CLI 
# Pack from directory
./cli/pack-seed.js --input ./data/ --output package.car

# Pack from JSON with metadata
./cli/pack-seed.js \
    --input data.json \
    --metadata meta.json \
    --output package.car

# Unpack to directory
./cli/unpack-seed.js --seed package.car --output ./extracted/

# Unpack with verification
./cli/unpack-seed.js \
    --seed package.car \
    --output ./extracted/ \
    --verify \
    --strict
DSSE Sign/Verify 
# Generate key pair
./cli/keygen.js --output keypair.json

# Sign a seed package
./cli/sign-seed.js \
    --seed package.car \
    --key keypair.json \
    --output signed.car

# Verify signature
./cli/verify-signature.js \
    --seed signed.car \
    --pubkey keypair.json \
    --verbose

# Batch verify multiple seeds
./cli/batch-verify.js \
    --seeds *.car \
    --pubkey keypair.json \
    --parallel 4
Round-trip Testing 
# Basic round-trip test
./cli/test-roundtrip.js --seed package.car

# Full integrity test with timing
./cli/test-roundtrip.js \
    --seed package.car \
    --iterations 100 \
    --timing \
    --memory-check

# Batch round-trip test
./cli/batch-roundtrip.js \
    --directory ./seeds/ \
    --output results.json \
    --parallel 8
Advanced Workflows 
# Create seed with custom schema
./cli/pack-seed.js \
    --input data.json \
    --schema custom-schema.json \
    --output custom.car

# Multi-format export
./cli/export-seed.js \
    --seed package.car \
    --formats car,json,yaml \
    --output ./exports/

# Diff two seeds
./cli/diff-seeds.js \
    --seed1 old.car \
    --seed2 new.car \
    --output diff.json
