Publishing Instructions

  1. Drop your artifact files (.htmlc, .cartridge, .fed.zip) into the drop zone above
  2. Wait for automatic BLAKE3 hash computation and DSSE detection
  3. Click "Generate index.json" to create the canonical artifact list
  4. Download the generated index.json file
  5. Commit the index.json to your repository at docs/exchange/index.json
  6. The exchange will automatically load artifacts from the JSON file
