## Reproducibility & Trust

All artifacts in this release are cryptographically signed using DSSE (Dead Simple Signing Envelope) attestation. The build process is fully deterministic and reproducible across platforms. Provenance data includes:

- Git revision and build timestamp
- Tool versions (Node.js, TypeScript, package dependencies)
- Input/output file hashes (SHA-256 + BLAKE3)
- Network function deltas and performance metrics
- Complete software bill of materials (SBOM)

Trust verification requires only the embassy package and standard crypto tools - no network access needed.

- Network-free operation requires all dependencies pre-bundled in embassy package
- Cross-platform reproducibility tested on macOS and Linux only
