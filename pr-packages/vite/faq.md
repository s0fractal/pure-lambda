# FAQ для мейнтейнерів

**Чи змінюється код / прод-біхевіор?**
Ні. Це окремий canary job у CI. Прод-збірка не торкається.

**Що як оптимізація зламає тест?**
Oracle блокує memo/par якщо є side-effects; equivalence-тести — обов'язкові; у разі чого — canary не блокує PR.

**Як відтворити локально?**
```bash
node --loader=@pl/loader node_modules/vitest/vitest.mjs run
```
(ті самі тести, додатково збережуться receipts).

**Що з ліцензіями/телеметрією?**
Плагіни read-only, телеметрія вимкнена; receipts — локальні артефакти CI.

**Як прибрати?**
Видалити canary job одним комітом.
